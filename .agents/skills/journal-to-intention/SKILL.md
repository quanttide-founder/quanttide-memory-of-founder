# 日志到意图

把 `<集>/journal/` 中的混合日志提取为**同一集** `<集>/intention/` 下的人类意图记录。intention 是对齐层：记录**人类到底想要什么**，用以对齐人机协作的信息。典型来源有两类：

1. **AI 问人类的时候**：AI 提问后人类给出的回答与澄清（包括"这个问题问得好，让我想清了意图"这类反照）。
2. **人机小交互出现摩擦时**：AI 做偏了、理解偏差、被当成纯执行者等摩擦现场，人类主动澄清"我要的是 X，不是 Y"。

## 层间分工

| 问题 | 去向 |
|------|------|
| 这是"我到底想要什么（对 AI 的澄清）"？ | `<集>/intention/` |
| 这是"我是什么样的人 / 我反复怎么判断"？ | `<集>/profile/` |
| 这是"我想通了什么机制"？ | `<集>/insight/` |
| 这是"我要做什么 / 选什么"？ | `<集>/roadmap/` |
| 这是"发生了什么"？ | 留在 `<集>/journal/` |

**判据**：意图必须能指导 AI 下一步怎么做——"要 X，不要 Y""先问再做""按 X 标准验收"。感悟、事件、无落点的感叹不收；拿不准就不收。

## 原则

- **单位是意图线索，不是日期文件**，多对多。
- **以最新为准**：人机协作的澄清会翻转，跨日合并、就地改写，被推翻的直接替换。
- **写给 AI 读**：祈使或明确陈述，去掉叙事铺垫，一条意图 + 一句背景。
- **与 profile / roadmap 分工不复制**：价值观式的稳定判断归 `<集>/profile/`，成形的决策归 `<集>/roadmap/`，本层只收协作现场尚未蒸馏为前两者的具体澄清；澄清沉淀为稳定特征或决策后，本层改写为互链。
- 目前仅 `default/` 启用本层；`write/` 集暂不设 `intention/`。

## 流程

1. **扫描**：通读本记忆集的全部日志——`<集>/journal/` 全部，加上集根的当天日志（如 `default/2026-09-26.md`），按摩擦与问答类关键词定位候选：问、回答、澄清、不对、不是这个、偏差、执行者、掌控、引导、提示词、约束、验收、别、要。不读其他记忆集的日志。
2. **过滤**：按判据过滤，能指导 AI 行为的才收。
3. **聚类**：同一意图跨日期合并为一条；被后续澄清推翻的就地改写。
4. **合并**：读现有 `<集>/intention/` 文件，新线索增条目，已有条目改写，过时的移除。

## 输出

`<集>/intention/` 按主题分文件（`default/` 如 `ai.md`），命名延续主题命名法，不用日期。条目一行一条：

```markdown
# 主题名

- **意图**：要 X，不要 Y。背景：摩擦或提问一句（YYYY-MM-DD）。
```

## 边界

- 不收事件经过（留 `<集>/journal/`）、稳定特征（归 `<集>/profile/`）、机制命题（归 `<集>/insight/`）、决策与目标（归 `<集>/roadmap/`）。
- 日志里没有的意图不编造；拿不准就不收。
- intention 是给 AI 读的对齐信息，不是建议，也不是对用户的输出。
