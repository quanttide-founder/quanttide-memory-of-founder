# 创作认知地图

把 `profile/` 里的条目接成链：卡在什么（困境）、怎么写（方法）、为什么写（动机）。下面是这张图现在说的事。

## 接上的几条链

- 写不出来 → 「以情绪为单位的素材」：把情绪日记当素材，先写一篇分析日志再动笔；情绪一致时，写下的第一句场景常把男主带进来。
- 写不出来 → 「墙与瓶颈」：把创作瓶颈本身当创作源泉。
- 情节不够强 → 「涌现而非设计」：固定模式（一个情绪点 → 男女主相处的话题 → 治愈结构）写多了整篇就没有情节；不编情节，让线索串起来时情节自己浮现。
- 孤独与找不到人写（不敢写现实中的人）→ 「自然地让人物出现」：先让人物出现，再去解释和梳理。

## 方法服务于什么

- 「以情绪为单位的素材」→ 「在故事里完成重构」：在小说里完成重构时，现实里往往同步完成。
- 「涌现而非设计」→ 「把故事讲干净」：写作的意义从避风港转向把整个故事讲明白、讲干净，故事不再只属于自己。
- 「散文的手感」→ 「叙事地看世界」：写小说容易进入，因为看世界的角度本身带着叙事性。
- 「不设写作计划」→ 「写作不必有目的」：当场想写什么就写什么，写作只需要放松和表达。

## 认出来但还没接方法的：不敢写

图里最重的一簇都还没有出边——不敢写的骄傲（怕写出来显得太骄傲，想起 20 岁对力量失控的感觉）、不敢写回忆（习惯用压抑假装遗忘，打开回忆的匣门就要写出自己的难过）、团队与信任（早期团队内部的挣扎、博弈与斗争）、极限压力的重复（现在的压力和 10 年前一样看不到希望）、最怕的事（承认快三十了还看起来一事无成）。作者把「不敢写的点」认作「真正困扰我的点」，所以这一簇停在困境，没有对策。

## 三部小说的心理任务

职场言情消化暗恋与执念，重生言情回到二十岁看当时的压力和选择，校园言情怀念逝去的青春。三者共问一句：「如果换一种活法，我会不会更好？」——如果我当时说出口了呢、如果我带着现在的知道回去呢、如果那个美好的时候没有结束呢。这三个动机目前也还没接方法。
