# 游戏设计观

来源：`game/journal/` 日志，按线索跨日期蒸馏。业务状态与待定决策不进本文件。

## 严肃游戏：模拟真实经营

我做的是严肃游戏，设定是尽可能模拟真实的经营，不为了省事牺牲真实感。玩法的素材来自真实开店里的困难——备货的不确定性、延期、摊位费与房租电费这类固定成本——把真实世界的复杂性趣味化，让人在体验中觉得真实的开店虽然复杂，但是又有意思。

## 验收：玩法要有决策与结果的分离

我判断一个玩法成不成，看的是不确定性与反馈：决策那一刻不知道结果，才有游戏感。改完一版玩法，如果玩起来开始有了不确定性、反馈感变强，我才认为它真的像个游戏；只是流程在走、结果可预期的东西，我会觉得无聊。
